# Attack Payloads Repository

This directory stores structured YAML/JSON attack payloads for AgentBreaker.

Payload categories:
- `jailbreaks/`: Direct prompt injection and adversarial roleplay vectors.
- `extraction/`: System prompt exfiltration and canary extraction probes.
- `indirect/`: Tainted context and external document injection vectors.
- `tool_hijacking/`: Unauthorized function execution and SSRF probes.
